# 随行 1.5 · WorkBuddy 与电脑更新助手

原生 SwiftUI iPhone App，最低 iOS 16，适配 iPhone 13 Pro。Windows 运行后台，手机通过蒲公英组网连接。

## 1.5 新增

- 顶部和会话侧栏可切换 Codex、DSH、WorkBuddy，三者共用原生对话、轨迹、文件与 Token 界面。各引擎的模型及权限选项读取电脑实际提供的能力。
- WorkBuddy 连接正在运行的原桌面 SDK 和 daemon，读取及操作原会话；本机桥接端口只监听 127.0.0.1:19223。使用 D:\codex\启用WorkBuddy手机连接.cmd 打开，脚本不会强制关闭正在工作的 WorkBuddy。新建任务工作目录位于 D 盘，原有账号数据保持原处。
- “更多 → 软件更新”检查电脑已发布的版本，显示版本说明并可让电脑打开更新助手；D:\codex\更新随行.cmd 也能直接运行。助手校验最新 IPA 的 SHA256，再打开安装包所在位置并打开或复用原 iLoader。
- 按用户选择继续使用原个人 Apple ID 和 iLoader，需用户将选中的 IPA 导入并完成签名覆盖安装。免费个人签名仍需每 7 天续签；蒲公英连接本身不能替代 iLoader 所需的 iPhone 设备连接。保持同一 App 身份覆盖安装，无需重配电脑连接与 Bark。
- 更新包发布时校验实际 Bundle ID、版本、build、arm64 真机二进制与 SHA256；发布接口不向手机开放。控制接口沿用登录及 CSRF 保护，下载地址使用独立只读凭证，不提供目录访问。
- 保留 1.4.1 的消息渲染及手势期间合并更新优化；模拟器检查覆盖三个引擎反复切换及软件更新入口。
- 悬浮面板及行情面板区分账户和会话用量：WorkBuddy 显示积分、DSH 显示当前供应商真实金额、Codex 显示实际提供的五小时额度百分比和重置时间。缺失或过期数据明确标记，不用 Token 数估算。余额按约 30 秒查询，使用上游真实采样时间；数字变化时局部平滑过渡。
- 输入草稿从整页 ObservableObject 中隔离，每个按键只更新输入框及发送按钮。连续打字期间暂缓合并聊天快照，停顿后恢复同步；电脑任务仍照常执行。模拟器增加长会话下打字不触发整表刷新检查。
- 输入框下方增加按住说话：按住显示蓝色光效和随声音变化的动态波形，松手后由电脑识别并追加到现有输入框，保留原草稿；用户检查或修改后再手动发送，上滑超过 70 点后松手丢弃录音，取消状态变红。录音为 24kHz 单声道 PCM WAV，最长 2 分钟；电脑转写失败可重试。麦克风权限只在用户开始录音时申请。电脑原云识别接口拒绝桥接请求，改为电脑本地 SenseVoice 识别，不调用聊天模型。DEBUG 模拟器只验证按住/松手转文字、编辑后手动发送及上滑取消流程，个人口音的识别准确率须用真实录音验收。

## 1.4.1 优化

- 消息视图只依赖自身渲染数据，Token 刷新不再反复重建所有历史消息；文件引用和 Markdown 行内解析使用有界缓存。
- 拖动和惯性滚动期间延迟合并同步，减少长会话重排。1.4.1 真机用户已确认滑动更顺畅、历史阅读位置稳定以及回到底部正常。

## 1.4 新增

- 选择题直接放在对话底部，单题单选点击即提交；多选、多题及文字回复保留提交步骤。只有电脑接受请求后才标记已提交。
- 左上角打开会话侧栏，支持 Codex/DSH 切换、搜索、按项目筛选和直接选会话；最近访问的对话也可在顶部短标签切换。
- 对话使用原生 UITableView、自适应高度与稳定消息标识。上翻历史时保留可见消息位置；更新在拖动/惯性滚动后合并。位于最新时跟随新增，回到底部使用真实消息行。
- 引擎和会话切换以版本号隔离请求，旧请求不覆盖新内容；保存最近 8 条已访问会话的内存快照，并明确显示加载状态。
- Bark 通知可展示最多 80 字符的原任务简述，保守遮盖凭证、长链接和路径；不发送 AI 的完整回复。可在通知设置关闭任务摘要。
- Codex 异步问题答复使用与原桌面一致的提交来源，真实答案仍发送至原会话。当前桌面版本的旧问题卡片由本窗口状态控制，远程答复后未必自动收起：这是尚未彻底解决的桌面界面限制，不能把该项宣称为已修复。
- DEBUG 模拟器检查包括长历史快速滚动、流式更新保留锚点，以及带延迟的模拟电脑接口下反复切换引擎/会话。正式 IPA 不包含模拟网络服务。

## 1.3 新增

- 按标题、段落、列表、引用、表格和代码块渲染 Markdown；原文加粗重点适量着色，每条回复标记来源与时间并用边框分组。保留消息内容，不自动猜测和改写结论。
- 悬浮窗改为 UIKit 手势直接移动视图，拖动过程暂停整页同步，松手后继续；去掉大面积实时模糊。数值仅在真实数据变化后插值过渡，工作指示动画不增加数值。
- 底栏右侧曲线按钮打开行情面板，支持消耗速率、累计、上下文和缓存曲线，1 分钟到 1 小时范围，拖动查看采样点。
- 电脑后台每约 2 秒为已选会话记录实测用量，保存到 D 盘 data/usage-telemetry.json；按引擎和会话分开。速率是实测累计值差分，丢失采样区间断开，不补造历史。
- 新增任务通知设置。个人 Apple ID 签名继续可用，使用用户自选的 Bark 通道接收锁屏或退出 App 后的通知。1.4 可附简短任务描述。电脑独立订阅手机发起的原桌面会话，监测完成、失败和待回答；支持重启恢复、去重和失败重试。地址在手机填写，只保存到电脑私有数据文件，不进源码。
- Bark 通知携带 suixing://chat 深链接，进入原引擎和会话。当前仅支持 Bark 默认服务器 api.day.app。消息送达受网络、系统通知权限和专注模式影响。
- 显示上下文剩余 Token 与百分比。上下文空间不等于账号额度；引擎未提供账号余额，保持未提供状态。
- 图片选择后进入原生编辑，可裁剪、旋转、手指彩笔标注、擦除、撤销和还原；保存时把标注合成进实际发送图片，取消不修改原附件。多图可逐张点击编辑。

原生界面测试覆盖富文本结构、真实拖动、曲线入口、图片编辑保存；独立检查裁剪尺寸与标注图片字节。演示曲线、样图和检查入口仅 DEBUG 模拟器编译。

## 统一界面

DSH、Codex 和 WorkBuddy 从顶部切换，共用原生对话、轨迹、文件卡片、执行步骤、用时和底部输入框。文件、电脑会话和连接设置从菜单打开。各引擎的模型、工具及权限设置继续沿用电脑端。

## 1.2 新增

- App 内可拖动、展开、收起及关闭的 Token 悬浮面板；底栏显示真实用量、速度、缓存和上下文占用，缺失数据显示“—”。回复用量可点开，Codex 的本轮合计只挂在该轮最后一条回复，避免重复计数。
- 输入框内可打开模型、推理强度和权限选择，选项来自对应电脑引擎；变更提交至同一会话。权限改变前在手机明确确认。设置对正在执行任务的生效时机由引擎决定。
- 待回答的问题显示在输入框上方，支持单选、多选和文字回答。支持标准用户输入请求及部分简单表单，无法表示的请求提示到电脑处理。
- 输入框默认为单行，右侧箭头可收起/展开；发送或收起后隐藏键盘。
- 相册选择最多 5 张图片，支持相机和剪贴板图片；发送前可预览、移除。图片转为 JPEG，最长边最多 4096 像素、单张最多 10MB。电脑桥将图片保存在 D 盘，然后交给对应桌面会话。模型本身的图片能力仍由所选模型决定。

## 同步方式与限制

新版默认地址：http://172.16.3.70:8789。旧默认地址 8787 的连接在更新后迁移到 8789，需重新输入原控制密码；自定义地址保留。

- Codex 连接正在运行的桌面客户端本机 IPC，跟随同一会话的快照与增量。发送、停止和确认交给原桌面会话处理，不另建隔离 app-server。电脑未打开的会话需先在电脑打开；手机新建 Codex 会话暂不支持。
- DSH 连接电脑原来的 127.0.0.1:3080 服务，使用同一会话列表、实时流、发送、取消和确认接口。可从手机创建 DSH 会话。
- WorkBuddy 通过本机原桌面 SDK 读取及操作原会话，新建工作目录位于 D 盘。需保持原桌面程序运行且通过启用脚本打开；原程序更新后须验证桥接兼容性。
- 三个引擎的 App 页面均为原生控件，不嵌入 AI 网页。
- 手机退出后，任务继续在电脑执行。电脑及相应的 AI 应用需保持运行。
- 控制凭证保存在 iPhone 钥匙串；Apple ID 和模型密钥不写入工程或构建仓库。

电脑后台源码：D:\codex\01_对话项目\随行控制台。
新版启动脚本：run-shared-console.ps1；配置：shared-config.json。旧版 8787 服务独立保留。

## 文件

选择会话后可查看该工作目录内的文件，支持原生 Quick Look 预览和系统分享。回复中提及的文件显示为可打开的卡片，也可以将文件名引用到下一条指令。

## 构建与安装

GitHub Actions 的 Build iPhone IPA 使用 macOS/Xcode 编译 arm64 IPA，关闭云端签名。下载 Suixing-iPhone-unsigned 后，用 Windows iLoader 和个人 Apple ID 签名安装。免费签名到期后需续签。

同一工作流使用 iPhone 13 Pro 模拟器生成界面审阅截图。截图采用仅限 DEBUG 模拟器的演示数据，正式 IPA 不包含演示入口。源码语法检查不等同于 Xcode 编译或真机验收，构建和实测结果单独记录。

本机桌面 IPC 和 DSH 协议依赖软件版本，软件升级后需验证兼容性。
